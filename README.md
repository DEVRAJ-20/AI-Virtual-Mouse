# 🖱️ AI Virtual Mouse

Control your computer's mouse cursor using **hand gestures** — powered by AI, OpenCV, and MediaPipe.

---

## ✨ Features

- 🖐️ **Hand Gesture Control** — Move the cursor by moving your hand in front of the camera
- 👆 **Click Detection** — Perform clicks using finger gestures
- 🗣️ **Voice Commands** — Control actions using voice input
- 🌐 **Web Dashboard** — Monitor and configure via a built-in web UI
- ⚡ **Real-time Tracking** — Smooth and responsive cursor movement

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Webcam

### Installation

```bash
# Clone the repository
git clone https://github.com/DEVRAJ-20/AI-Virtual-Mouse.git
cd AI-Virtual-Mouse

# Install dependencies
pip install -r requirements.txt

# Run the application
python src/main.py
```
